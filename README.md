VELMORA is a vintage travel poster for a place that isn't there: a dusk
sky with stars and floating islets, a low sun over layered mountain
ridges, a calm sea with a sun path, and the place name set large in
cream lettering as the only text. It is drawn pixel by pixel in pure
Python (standard library only) and written as a 768x1024 PNG.

## Run it

```sh
python3 main.py
# writes /output/entry.png
```
